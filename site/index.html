Everything a general store needs

Built around how shopkeepers actually work.

🛒

Fast POS

Barcode or name search, discounts, and Cash, Bank, Easypaisa, JazzCash or Credit/Udhaar payments.

📒

Digital khata

Customer balances are always calculated from records. Statements and WhatsApp payment reminders.

📦

Inventory control

Stock can never go negative. Every change is logged. Low-stock alerts and stock value.

🚚

Suppliers & purchases

Record purchases, track what you owe, and pay suppliers in part or in full.

📊

Profit insights

Live dashboard, best sellers, receivables and expenses. PDF and Excel reports.

🧾

Urdu invoices

A4 PDF invoices in English or Urdu, plus 80mm thermal receipts for shop printers.

↩️

Returns, void & delete

Handle returns and mistakes safely. Owners can delete records with clear warnings.

🔐

Roles & backups

Owner and Cashier roles, CSRF protection, hashed passwords, automatic daily backups.

Read-only AI assistant

Ask questions about your shop, answered from real data only. Your API key stays in an environment variable.

Run it on your computer

ShopStock keeps shop data on the shop's own PC, so it runs locally.

git clone https://github.com/YOUR-USERNAME/ShopStock.git
cd ShopStock
pip install -r requirements.txt
python app.py   # opens http://127.0.0.1:5000
# first login: admin / admin123 (you must change it right away)
Why isn't there a live demo here? A shop database holds real customer and money records, so it belongs on the shop's own computer, not on a public web server. This page is the project showcase. The full source and a step-by-step guide are on GitHub.
